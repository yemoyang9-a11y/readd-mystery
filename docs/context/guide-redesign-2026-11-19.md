## 2. 새 가이드 (8단계 제안)

원칙: **한 단계 = 한 기능 설명 + 누르는 것 최대 한 번.** 같은 화면에서 이어지는 단계끼리 묶어 왔다 갔다를 줄이고, 독자가 직접 해 볼 필요가 없는 동작(다음 페이지, 보내기, 닫기, 끝까지 넘기기)은 가이드가 대신 해 준다. 모든 단계에 "다음"(오른쪽 아래), "건너뛰기"(화면 오른쪽 위)는 그대로.

| # | 화면 | 아모가 알려 주는 것 (말풍선 요지) | 독자가 하는 일 |
| --- | --- | --- | --- |
| 1 | 홈 | **RE:ADD가 뭔지**: 추리소설을 읽다 잊은 인물·사건을 바로 되찾게 돕는 곳. 무엇이든 **차례로 읽은 쪽까지만** 보여 줘서 스포일러가 없다 | 데모 책 표지 누르기 |
| 2 | 브리핑 | **지난 줄거리(리캡)**: 다시 펼치면 읽은 데까지 줄거리를 정리해 둔다. 오래 쉬었다 와도 바로 이어 읽는다 | "이어서 읽기" |
| 3 | 본문 | **문장 고르기**: 메모하고 싶은 문장을 길게 누르면 노트에 적거나 아모에게 물을 수 있다 | 표시된 문장 누르기 → "노트에 적기"(노트 창은 가이드가 자동 저장) |
| 4 | 사이드 탭 · 추리 노트 | **사이드 탭이 뭔지**(읽다가 옆에서 여는 네 가지 도구) + **추리 노트**: 적은 단서·가설이 쪽수와 함께 모인다 | (가이드가 사이드 탭을 연다) 확인만, "다음" |
| 5 | 사이드 탭 · 타임라인 | **타임라인**: 다 읽은 장의 핵심 한 줄과 그 장의 사건을 한눈에. 읽는 중인 장은 다 읽으면 정리된다 | 장 하나 눌러 사건 펼치기 |
| 6 | 사이드 탭 · 인물관계도 | **인물관계도**: 지금까지 드러난 인물 관계만(가족·직업·감정 등). 읽을수록 선이 늘어난다 | 인물 하나 누르기 |
| 7 | 사이드 탭 · 아모 | **아모**: 읽은 쪽까지의 내용으로 답하는 친구. 추리가 맞는지 판정하거나 범인을 말하지 않는다. 답 속 p.쪽수를 누르면 그 쪽으로 갔다 돌아올 수 있다 | 추천 질문 하나 누르기(가이드가 바로 보내고 답을 보여 줌) |
| 8 | 마무리 카드 | **완독자 이야기방**: 끝까지 읽으면 같은 책을 다 읽은 독자들과 이야기한다 + 사이드 탭은 읽기 화면 오른쪽 손잡이로 언제든 연다 | "홈으로" |

- 15단계 → **8단계**, 독자가 누르는 횟수 약 20번 이상(끝까지 넘기기 포함) → **7번**.
- 빠지는 것: 다음 페이지 넘기기, 노트 저장, 질문 보내기, 사이드 탭 닫기, 끝까지 넘기기(가이드가 대신하거나 설명으로 대체).
- 들어오는 것: RE:ADD 소개(1), 사이드 탭 소개(4), **타임라인(5)**, 쪽 링크 안내(7).

## 3. 정해 주실 것

1. 8단계 구성과 순서가 괜찮은지 (예: 리캡을 2단계에 둘지)
2. 7단계에서 아모 답을 실제로 기다리게 할지, 데모용 미리 쓴 답을 바로 보여 줄지(데모 책은 실제 서버를 부르지 않으므로 지금도 미리 쓴 답)
3. 완독자 이야기방을 마무리 카드 설명으로만 둘지, 실제 화면을 한 번 보여 줄지
