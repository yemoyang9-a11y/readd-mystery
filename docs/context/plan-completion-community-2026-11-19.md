# 계획 — 마지막 쪽 알림창과 완독 판정 (2026-11-19, 대표 검토 대기)

대표 지적: "책 끝까지 읽어도 커뮤니티가 안 들어가지고 책 다 읽고 와야 한다고 빠꾸 먹는다. 마지막 쪽에 오면 알림창으로 '커뮤니티로 이동할까요?'가 뜨게 하고, 메인 화면에서 커뮤니티로 들어갈 때도 완독 판정을 정확히 어떻게 할지 계획을 세워라."

## 1. 왜 막혔나 (운영 DB 확인, 2026-11-19 09:01 기록)

- 「가상범인」 68쪽 중 **1~63쪽은 "차례로 읽음"으로 인정, 64~68쪽은 인정 안 됨**. 지금 있는 쪽 = 68, 가장 멀리 간 쪽 = 68.
- 완독 = "1쪽부터 끊김 없이 차례로 읽었다고 인정된 마지막 쪽 ≥ 마지막 쪽"(CLAUDE.md 3장, 2026-11-17 대표 결정). 63쪽에서 끊겼으므로 서버 판정은 "63쪽까지 읽음 = 미완독" → 커뮤니티 403.
- 읽음으로 인정되는 건 '다음' 넘김, 1쪽 도착, 목차 확인 창의 "앞부분은 이미 읽었어요", 사이드 탭 확인 카드의 "N쪽까지 읽었어요"뿐이다. **아모 답의 쪽 링크(p.66), 목차 "이동만 하기", 노트에서 쪽으로 가기, 앱 재진입은 위치만 옮긴다.** 이번 기록은 63쪽 근처에서 이런 이동으로 68쪽에 간 것으로 보인다.
- 그 상태에서도 사이드 탭에 "68쪽까지 읽었어요?" 확인 카드가 뜨게 되어 있지만, 사이드 탭을 열어야만 보여서 놓치기 쉽다.

## 2. 완독 판정 원칙 (바꾸지 않는 것)

- 완독 여부는 **서버의 기준점 결정기(getCutoffSnapshot의 is_complete) 한 곳**에서만 정한다(R2, D14). 화면은 마지막 쪽에 왔는지로 완독을 계산하지 않는다(절대 규칙 2).
- 완독으로 올리는 입력은 지금처럼 **'다음' 넘김**과 **서버가 낸 확인 질문에 독자가 답한 것**(claim)뿐이다(절대 규칙 8). 화면이 "완독"을 서버에 보내는 길은 만들지 않는다.
- 이유: 목차로 마지막 쪽만 열어 보고 커뮤니티에 들어가 결말 토론을 보는 일을 막기 위해서다(완독자 커뮤니티 = 스포일러가 있는 곳).

## 3. 마지막 쪽 알림창 (새로 만들 것)

독자가 마지막 쪽에 도착하면(어떤 방식으로 왔든) 서버 응답을 보고 둘 중 하나를 띄운다.

| 서버 판정 | 알림창 문구(안) | 버튼 |
| --- | --- | --- |
| 완독(is_complete) | "끝까지 읽으셨어요. 같은 책을 다 읽은 독자들과 이야기하러 갈까요?" | [커뮤니티로 가기] [나중에] |
| 아직 아님(차례로 읽은 쪽 < 마지막 쪽) | "p.64부터 p.68까지는 건너뛰신 것 같아요. 이 부분도 읽으셨나요?" | [다 읽었어요] [p.64부터 읽기] |

- "다 읽었어요" = 지금 사이드 탭 확인 카드와 같은 서버 질문의 답(claim). 누르면 서버가 1~68쪽을 읽음으로 인정 → 완독 → 바로 위 "커뮤니티로 가기" 알림창으로 이어진다.
- "p.64부터 읽기" = 건너뛴 첫 쪽으로 이동(위치만 옮김).
- 숫자(p.64)는 서버가 준 값만 쓴다. 화면이 계산하지 않는다.
- 한 책에서 "나중에"를 누르면 그 기기에서는 다시 띄우지 않고, 마지막 쪽의 완독 배지로 다시 열 수 있다(지금 완독 화면과 같은 방식).
- 서버 조회가 실패하면 알림창을 띄우지 않는다(실패 = 미노출, R11).

## 4. 메인 화면·커뮤니티 허브에서 들어갈 때

- 판정은 같다: 서버 is_complete만. 미완독 책은 지금처럼 잠김.
- 잠긴 책을 누르면 지금은 "다 읽고 와야 한다"만 나온다 → 바꾼다:
  - 마지막 쪽까지 **펼쳐 본 적이 있는데**(가장 멀리 간 쪽 = 마지막 쪽) 차례 읽기가 끊긴 경우: 위 표의 "건너뛰신 것 같아요" 창을 그대로 띄운다(다 읽었어요 / p.N부터 읽기).
  - 아직 마지막 쪽까지 가지 않은 경우: "완독하면 열려요. 지금 p.N까지 읽으셨어요." + [이어 읽기].
- 커뮤니티 서버 관문(403)은 그대로 둔다. 화면 쪽 안내만 친절하게 바꾼다.

## 5. 시험(구현 때)

- 마지막 쪽 도착 + 서버 완독 → "커뮤니티로 가기" 창 1개 / 서버 미완독 → "건너뛰신 것 같아요" 창, 커뮤니티 창 0개(쌍)
- "다 읽었어요" → 진도 요청에 서버 선택지의 답(claim)만 실리고 쪽 숫자를 기준점으로 보내지 않음(절대 규칙 8)
- 목차로 마지막 쪽만 연 독자: "다 읽었어요"를 누르기 전 커뮤니티 접근 403 유지(게이트 0건)
- 서버 조회 실패 → 알림창 0개

## 6. 정해 주실 것

1. "건너뛰신 것 같아요" 창에서 [다 읽었어요] 한 번으로 완독 인정해도 되는지(지금 사이드 탭 확인 카드와 같은 수준의 신뢰). 더 엄격하게 하려면 건너뛴 쪽을 실제로 넘겨야만 인정.
2. 알림창 문구
3. 시안을 먼저 볼지, 바로 구현할지(규칙상 새 창은 시안 먼저)
