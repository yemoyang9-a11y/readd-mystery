검수 비용같은 장을 두 번 독립 추출해 일치한 항목만 확인됨으로 표시하고, 관계마다 근거 인용문을 다시 확인. 인용문·쪽수는 규칙으로 검사한 뒤 사람이 최종 검수. 책 1권 분석 비용과 검수 시간은 추리 파이프라인으로 다시 측정 중(이전 버전 측정값 약 140~270원)
결말 누설원문 출력 차단. 질문 유형별(현재 사실 / 아직 안 나온 사실 / 범인 추리 유도 / 틀린 전제 / 우회 질문) 누설 시험. 현재 130건 중 자동 판정이 표시한 13건을 사람이 읽어 누설 0건, 나머지 117건은 미확인. 출시 전 전체를 사람이 판정해 0건일 때만 공개
