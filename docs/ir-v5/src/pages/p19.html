출판사 제안 조건
우리가 드리는 조건
  • 비독점, 국내 한정, 본문 파일 내려받기 없이 화면에서 열람만(캡처·복사 막기는 앱 전환 때)
  • 선지급 없이 구독 매출의 50%를 매월 정산
  • 책별 데이터를 출판사에 공개: 판매, 완독률, 독자가 멈춘 장면, 질문이 몰린 장면
  • AI 이용 허락은 공급 계약의 기본 조건(범위는 오른쪽 항목)
  • AI 학습에 쓰지 않도록 각 업체 설정을 끄고 계약서에 명시
  • 계약 종료 시 요약·임베딩·관계도 삭제(삭제 절차는 출시 전 마련)
  • 이용 데이터(완독률·전환율 등)는 보관. 범위는 법률 자문 후 확정
  • 30일 전 통보로 철회 가능
계약서에서 허락받을 항목
  1. 전자책 본문 게재
  2. 파일 변환과 서버 저장
  3. 외부 AI 업체(OpenAI·Anthropic·Cohere)로 본문 전송
  4. 검색용 임베딩 생성
  5. 요약·인물 정보 생성
  6. 원문 인용(길이 상한 포함)
  7. 구독 상품으로 제공(한 달 기간제 열람)
  8. 작가에게서 위 권한을 받았는지 확인
정산: 구독 매출의 50%를 그달 읽힌 횟수로 나눕니다. 무료 체험 기간에 읽힌 책의 정산 방식은 출판사와 협의해 정하며, 현재 계산은 무료 기간에 지급이 없다고 가정했습니다.
책별 데이터 공개는 리디가 초기에 출판사에 판매 데이터를 바로 보여 준 방식에서 가져왔습니다(출처 확인 중).
