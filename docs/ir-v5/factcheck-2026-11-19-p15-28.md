### 꼭 고쳐야 할 것 (우선순위)

1. **15쪽 각주 "웹 결제와 앱 안 결제를 모두 지원합니다"**: 결제 기능이 코드에 없고(결제 관련 코드 grep 0건), 앱도 없다. 결제 방식도 아직 정하지 않았다(decisions.md "결제 방식 … 미정").
2. **15쪽 로드맵**: 추리 노트·타임라인·완독자 커뮤니티가 "다음 단계"에 있는데 이미 main에 구현되어 있다. 로그인도 이메일이 추가됐다. 반면 「가상범인」 "사람 검수"는 아직 진행 중이다(T16).
3. **16쪽 결말 누설 "원문 출력 차단"**: 실제는 답변당 원문 200자 상한이다(결정 34). 질문 유형 5가지도 실제 시험 범주(12개)와 다르다. 누설 시험 결과는 하네스 변경 전에 낸 것이라 다시 돌려야 한다(T3).
4. **18쪽 "AI 학습·미세조정에 쓰지 않음"**: 관계 추출이 Claude 소비자 구독(Max)으로 돈다. Anthropic 소비자 약관(2025-08-28 변경)은 Pro·Max(Claude Code 포함) 대화를 사용자가 끄지 않으면 학습에 쓴다. Cohere도 끄는 설정(opt-out)이 따로 있다. 설정을 확인하기 전에는 출판사에 이 약속을 할 수 없다.
5. **19쪽 수익 구조 막대 "AI 비용 0.8%"**: 하한값(78원)이다. 손익표(22쪽)의 매출원가는 상한값 474원(4.8%)으로 계산되어 있다. 두 쪽이 다른 값을 쓰고 있다.
6. **21쪽 생애 가치**: 표시된 식(5.6 × 4,100~4,500)대로 계산하면 2.3만~2.5만 원이다. 2.6만 원은 반올림하기 전 값이라 식과 맞지 않는다.
7. **21쪽 "완독자 글 공유(결말은 가림)"**: 공유 기능도, 결말 가리기 기능도 없다.
8. **22·25쪽 AI 비용 구조**: 지금은 OpenAI(챗봇·리캡·요약·인물·사건, 사용량 과금)와 Claude 구독(관계 추출, 정액)으로 나뉜다. 손익표에는 "개발 도구(Claude Max)"로만 들어가 있고, 비용 근거 출처(26·27쪽)는 Claude Haiku 가격이다.
9. **25쪽 출판사 몫 70%일 때 손익분기 "약 150명"**: 312,000 ÷ 2,169 = 143.8명이다. 또 50%의 손익분기는 1년 차 고정비로, 60%·70%는 3년 차 고정비로 계산해 기준이 섞여 있다.
10. **22·25쪽 서버 "현재 구성 기준 월 약 $30"**: 현재 구성은 유휴 시 월 $0.1 안팎, Supabase 무료 등급이다(architecture-current.md 7장). $30은 운영을 늘릴 때의 가정이다.

### 대표가 결정할 것

- 결제 방식(웹/앱, 결제 대행사)과 "체험 시작 시 결제수단 등록"을 출시 범위에 넣을지 (15·20·24쪽)
- 관계 추출을 Claude 소비자 구독으로 계속 돌릴지. 돌린다면 ① "Help improve Claude" 학습 허용 끄기 확인 ② 구독을 제품 파이프라인에 쓰는 것이 약관상 괜찮은지 확인 ③ Fly 서버의 관리자 업로드에서는 claude CLI가 없어 관계 단계가 실패하는 문제(tasks.md 5장 aefe0cc) 처리. 결과에 따라 18쪽 "AI 학습에 쓰지 않음"·"외부 AI 업체" 문구와 22쪽 비용 줄이 바뀐다
- 생애 가치·해지율 참고치를 "AI 외 앱"(월 구독 12개월 유지 9.5%)으로 둘지, "AI 앱"(6.1%)으로 바꿀지. RE:ADD는 AI 기능이 있는 앱이다. 6.1%로 바꾸면 해지율 약 20.8%, 평균 약 4.8개월, 생애 가치 약 2.0만~2.2만 원, 협업 기준은 약 0.85만~0.93만 원이 된다
- 21쪽 "대학 추리 동아리" 경로를 유지할지 (고객 정의에서 나이가 빠짐, 2026-11-18. 지난 사실 확인부터 대기 중)
- 21쪽 "완독자 글 공유"와 20·21쪽 "친구 초대 1개월 무료"를 계획으로 남길지, 뺄지
- 18쪽 "리디가 초기에 판매 데이터를 바로 보여 준 방식": 출처가 없다. 출처를 찾아 넣을지, 문장을 뺄지
- 손익분기 계산 기준(1년 차 고정비 / 3년 차 고정비)을 하나로 맞출지

## 계산 재현 방법

아래 식을 월 단위로 36개월 돌렸다(임시 스크립트, 저장소에 넣지 않음):

```
c = 0.178, conv = 0.425
T(월 새 체험자) = 각 해 12개월 선형: 83→310, 310→786, 786→1,149
S_m = S_{m-1} × (1 − c) + T_{m-1} × conv        (S_0 = 0)
매출_y = Σ S_m × 9,900
매출원가_y = 매출_y × (0.5 + 0.033) + Σ (S_m + T_m) × 474
결과: 연말 472 / 1,338 / 2,301명, 매출 2,681 / 10,462 / 22,184만, 매출원가 1,669 / 6,389 / 13,436만
```

체험자 수를 달마다 어떻게 늘리는지는 덱에 적혀 있지 않다. 선형으로 가정했을 때 덱 숫자와 ±6만 원 안에서 맞는다.
