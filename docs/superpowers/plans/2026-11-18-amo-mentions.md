# 작업 계획 — 아모 답변의 인물 강조·쪽 링크 (2026-11-18, 시안 검수 대기)

대표 지시: 챗봇에서 인물 언급은 색으로 강조, 쪽 언급(p.13)을 누르면 그 쪽으로 이동하고 원래 읽던 곳으로 되돌아가는 장치. 조사: [research-2026-11-18-chat-page-links.md](../../context/research-2026-11-18-chat-page-links.md). **시안 승인 전에는 구현하지 않는다.**

## 지켜야 할 것

- 기준점: 쪽 링크로 이동해도 읽음 인정은 없다(목차·노트 이동과 같음, R1·FR-PRG-003). 이동은 `from_page`가 `page - 1`이 아니므로 서버가 인정하지 않는다. 클라이언트는 기준점을 계산하거나 보내지 않는다(절대 규칙 2·8).
- 본문은 제한하지 않는다(R3). 링크는 1 ~ 마지막 쪽 범위의 숫자만 걸고, 기준점 초과 여부는 판단하지 않는다(절대 규칙 7). 아모가 기준점 초과 쪽을 말하지 않는 것은 서버 출력 검사가 이미 맡는다.
- 인물 강조 목록은 서버가 기준점으로 거른 인물관계도 응답(`nodes`의 이름·별칭)만 쓴다(FR-SPL-002). 새 API·새 조회 없음.
- 출력 검사(`output-guard.ts`)는 그대로. 화면에서 글자를 꾸미기만 하고 답변 문장은 바꾸지 않는다(절대 규칙 11).
