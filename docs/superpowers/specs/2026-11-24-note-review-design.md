## 1. 무엇을 만들었나

1. **내 추리 채점 화면** `/books/:bookId/review` — 끝까지 간 독자가 읽는 동안 남긴 가설·단서 노트를 AI가 한 번 채점한다.
2. **결과지 공유** — 채점 결과의 요약 카드와 독자가 고른 노트를 그 책의 완독자 커뮤니티에 글로 올린다.

## 4. 지시에 없어서 내가 정한 것 (대표 확인 필요)

- **노트 내용 수정 시각(`content_updated_at`)을 새로 둠.** `updated_at`은 '풀림' 표시만 바꿔도 움직여, 결말 뒤 '풀림'을 누른 노트가 채점에서 빠지기 때문. "결말 뒤 고친 노트 제외"를 **본문 글자·쪽·종류를 바꾼 경우**로 해석했다(쪽·종류는 교차 검토 지적 — 결말 뒤 쪽을 앞당기거나 가설로 바꿔 결과지를 부풀리는 것을 막음).
- **칭호 기준(임시)**: 명탐정 = 적중 ≥ 1이고 적중 ≥ 판정한 가설의 절반 / 조수 = 적중·부분 적중·핵심 단서 중 하나라도 / 견습 탐정 = 그 밖.
- **한마디 없이 공유하면 글 본문은 "내 추리 결과지를 공유했어요"** (DB 제약상 본문을 비울 수 없음). 화면은 카드의 한마디를 본문 자리에 그리므로 이 문구는 보이지 않는다.
- **근거 쪽은 글자만**, 그 쪽으로 이동하는 링크는 없음(읽기 화면 밖에서 쪽 이동 시 진도 이벤트 규칙 확인 필요).
- **채점 경로는 로그인 필수 목록에 넣지 않음.** 2026-11-18 결정("로그인 필요 경로는 셋")을 지키고, 로그인 없이는 끝까지 갈 수 없어 서버 관문으로 충분.
- **실패 재시도 횟수 상한 없음**(결정 12). AI 비용이 반복 실패로 늘 수 있다.
- **채점에 보내는 노트는 60개까지**, 넘는 노트는 판정 보류.

- **신고로 숨겨진 결과지 글도 '공유한 글'로 센다.** 숨겨진 뒤에는 다시 공유할 수 없고 채점 화면은 그 글로 가는 버튼을 보여 준다(글은 안 보임). 기존 정책(숨김 글은 작성자에게도 안 보임)과 색인 때문. 바꿀지 대표 확인 필요.

## 5. 교차 검토 (2026-11-24)

다른 에이전트가 코드만 보고 검토했다(같은 Claude 계열 — 이 환경에 다른 회사 모델이 없음). 스포일러 누출은 없음. 고친 것:
1. 멈춘 요청이 20분 뒤 다른 요청에 넘어간 다음 늦게 끝나면 기록을 덮거나 독자에게 다른 결과를 보여 줄 수 있었음 → 요청마다 표(claim_id), 표가 다르면 반영 안 하고 저장된 결과를 줌. 멈춤 판정을 5분 → 20분(게이트웨이 최대 대기보다 길게)
2. 결말 뒤 노트 쪽을 앞당기거나 종류를 바꿔도 결말 전 노트로 남아 "N쪽 전에 맞혔어요"를 부풀릴 수 있었음 → 내용 수정 시각에 쪽·종류 포함
3. 노트 본문으로 노트 묶음의 끝을 흉내 내 다른 노트 판정을 바꾸게 할 수 있었음 → 노트를 JSON 배열로만 보냄
4. 싸비 미완비 책에도 채점 버튼이 보였음 → 버튼 숨김(서버는 원래 404)
남김: 숨겨진 결과지 글 처리(4장 마지막 항목).
